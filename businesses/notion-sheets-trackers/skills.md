# Skills, tools and division of labour

## Skills needed
| Skill | Level | Free tool | Paid option |
|---|---|---|---|
| Spreadsheet design (formulas SUMIFS/COUNTIFS/dates, data validation, conditional formatting, charts) | intermediate | Google Sheets, LibreOffice, Python openpyxl (`build/make_xlsx.py`) | Excel 365 |
| Notion databases, relations, rollups, formulas, linked views, publish-as-template | intermediate | Notion free plan | Plus ($) if you need more guests - not needed |
| Basic US freelance tax literacy (Schedule C, SE tax, estimated periods) | basic - to avoid wrong claims | IRS.gov, Pub 505, Form 1040-ES | CPA review of the estimator once (~$100-200) |
| Listing images / mockups | beginner | Canva free, screenshots of the DEMO files | Canva Pro ~$15/mo |
| Etsy SEO | beginner | Etsy search suggestions, eRank free tier | eRank Pro, Marmalead |
| Pinterest marketing | beginner | Pinterest business, Canva pin templates | Tailwind |
| Customer support / licensing text | basic | Etsy messages | - |

## What Claude can do
- Generate/modify the xlsx workbooks with formulas, verify them with a formula engine, add new products (#6-#10) using the same script.
- Write all listing copy, FAQs, delivery PDFs text, pin text, email scripts, Notion page text, CSV/database specs and formulas.
- Review competitor listings you paste in (review mining), build keyword tables from eRank exports, draft tax-year updates each January.
- Cannot: log into Etsy/Notion/Google for you, create the Notion workspace natively, see live marketplace stats, or confirm a template opens in your Excel/Sheets.

## What the human must do
1. Create Etsy account/shop, pass identity verification, add bank for payouts, set tax info (W-9 etc.). Also Payhip/Gumroad accounts if used.
2. Import xlsx to Google Sheets, test; then create a view-only "Make a copy" link if selling Sheets links (or deliver the .xlsx as the file).
3. Build the Notion workspace from CSV + `BUILD_GUIDE.md`, publish the duplicate link, test in a second account.
4. Make listing images in Canva using screenshots; upload listings (Etsy has no practical API for individuals - uploading is manual; copy from `listings.md`).
5. Answer buyer messages; collect reviews ethically (no incentives for positive reviews).
6. Keep the tax-year constants current (Settings sheet) and have a tax professional glance at the estimator wording.

## Learning path (about 3 weeks, part-time)
1. Week 1: Etsy Seller Handbook (fees, digital listings, Creativity Standards); open the shop; read 20 competitor 1-3 star reviews.
2. Week 2: Open each xlsx, trace formulas (Tax Estimator, Invoices); import into Google Sheets; learn Notion relations/rollups with the guide.
3. Week 3: Canva basics for thumbnails; Pinterest pin design; eRank keyword check; publish.
4. Ongoing: monthly stats review; each January, update rates and re-release.
