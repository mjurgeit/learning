# Skills and tools needed

## What Claude can do vs. what the human must do
| Task | Claude | Human |
|---|---|---|
| Interior generation (Python/reportlab), puzzle grids, journal layouts | Yes, done for 2 books | Review proofs |
| Content (prompts, word lists, trivia, crossword clues) | Writes drafts | Edit, fact-check, disclose AI use |
| Metadata (title, subtitle, keywords, descriptions) | Yes | Validate keywords in Amazon search/tools |
| Cover design | Writes brief, can generate SVG/HTML covers and dimension math | Final cover in Canva or KDP Cover Creator, export PDF |
| KDP account, tax interview, ID, bank/payout | No | Required |
| Upload (KDP has no public API for books) | No | Upload via web dashboard, set price, tick AI disclosure |
| Proof copies, quality check | No | Order and inspect |
| Reviews/ads management | Can analyse exported reports | Run campaigns, approve spend |

## Tools (free first)
- Python 3 + reportlab (free) for interiors; pypdf for checks; poppler (pdffonts, pdftoppm) for validation.
- Canva free tier or KDP Cover Creator (free) for covers; Inkscape/GIMP free; Google Fonts (check license).
- KDP Previewer (free, in the upload flow) to check margins.
- Keyword research: Amazon autocomplete (free), Publisher Rocket (paid, one-time about $99 [blog-claim]), KDSPY/Helium 10 free trials.
- Optional: Book Bolt/ Vellum alternatives not needed. A sudoku/crossword generator script by Claude (free).

## Learning path (about 10 hrs)
1. Read KDP help: content guidelines, paperback formatting, trim sizes, pricing, AI disclosure.
2. Order 2 proofs; learn to read gutter/margin issues.
3. Learn KDP Ads basics (auto vs manual, ACOS).
4. Learn Amazon keyword research: autocomplete, competitor "bestseller rank" estimation.
5. Learn Canva cover layout and thumbnail legibility.
