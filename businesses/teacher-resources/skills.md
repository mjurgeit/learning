# Skills and tools: teacher resources

## Needed skills
1. **Pedagogy/standards literacy**: read CCSS 3.NF and Texas TEKS Grade 3 text; understand fraction models (bars, number lines). Learn from the standards documents themselves (corestandards.org, tea.texas.gov).
2. **Product build**: Python + reportlab (free) to generate PDFs, or Canva (free tier; Pro ~$15/mo) / Google Slides for manual layout. Script is `products/build_pdfs.py`; run `pip install reportlab`.
3. **Listing SEO**: keyword research via Etsy/TPT autosuggest, Pinterest search suggest, eRank/Marmalead (paid, optional).
4. **Visuals**: preview images 1000x1000+ (Canva), mockups of printed pages (free mockup tools).
5. **Pinterest basics**: vertical pins, boards, keyword-rich descriptions.
6. **Bookkeeping**: simple sheet of sales and fees; tax questions go to an accountant.

## Cost table
Python/reportlab $0; Canva free $0 (Pro optional); TPT Basic $29 once, Premium $59.95/yr [blog-claim]; Etsy $0.20/listing; Pinterest free; Payhip free tier (optional own store).

## Claude can do
- Write/extend the generator for new product sets, compute and verify answer keys programmatically, write listing copy, descriptions, FAQs, pin text, keyword lists, bundle structure, results tracker, and review PDFs for errors.
- Draft customer-service replies and a TEKS/CCSS crosswalk (must be human-verified).

## Human must do
- Create TPT and Etsy accounts, identity/tax verification, payout setup (PayPal/bank), accept terms (check current AI and IP rules).
- Print and classroom-test one product (ideally ask a teacher friend), review the answer key.
- Upload files and preview images (no API for TPT; Etsy upload is manual unless using API), set prices, press publish.
- Create Pinterest account and approve posts; respond to buyer messages; handle taxes.
- Verify TEKS numbering against current TEA documents.

## Learning path (about 4 weeks, 3-5 h/week)
Wk1: read CCSS Grade 3 fractions + TPT seller guidelines + Etsy Creativity Standards. Wk2: run `build_pdfs.py`, change seeds, add one new worksheet function. Wk3: Canva thumbnails, listing SEO. Wk4: Pinterest basics, analytics review.
